# 动画十二原则与表演设计

十二原则是设计根本：每次逐项审视其作用，再把适用项转译为可见动作，而不是仅写“运用十二原则”。不设选用数量配额，不要求每镜全用，也不要求更改原美术风格。无明显错误还不够，要让观众实际看到动作的弹性、重量、节奏与角色个性。

## 从意图到身体

先完成 [逐角色动势分析](character-motion.md)，再根据大概情景确定角色目标、行动步骤与关键姿势；已有具体动作则在其约束内细化。考虑支撑点、重心、接触对象、材质和停止方式。组织目光、头部、躯干与肢体的先后，用必要的行动和反应把情景演出来，不增加无关支线或改掉用户指定的结果。所有角色都考虑十二原则，强弱分级决定可见幅度和节奏，不决定只用其中几条。

| 原则 | 在提示词中落实的细节 | 适用边界 |
|---|---|---|
| 挤压与拉伸 Squash and Stretch | 明确受力部位与方向：承重时压低并横向展开，蹬离时沿发力方向伸展，接触后压缩再回弹；保持总体体积与辨识度 | 按材质与演出强度选择幅度，不默认只能轻微；刚性部件通过关节和柔性附件表现弹性 |
| 预备动作 Anticipation | 起跳前屈膝压低重心，伸手前肩臂轻微回收，先显出发力方向 | 克制动作可很小；立即发生或故意突发不能一律加长预备 |
| 舞台调度 Staging | 关键姿势轮廓清楚、视线目标可辨，一个时刻有明确注意中心 | 与分镜和构图共同解决；不借调度改变锁定的站位或关系 |
| 连续动作与关键姿势 Straight Ahead / Pose to Pose | 固定起点、接触点、转折点、终点，再用连贯运动连接；流体等连续变化写出发展趋势 | 这是组织方法，不是假想生成平台的参数；不输出抽象方法名代替动作 |
| 跟随与重叠 Follow Through / Overlapping Action | 骨架先改变运动，腹部、面颊、皮肉或柔性附件滞后；急转时向转弯外侧偏移，主动作停后越过平衡位置再逐次减幅回弹 | 选参考角色实际存在且适合的部位，写清触发与方向；不把全身做成同频抖动或脱离骨架的液体 |
| 缓入缓出 Slow In / Slow Out | 启动先慢后快、接近目标再减速；接触前后的速度变化清楚 | 撞击可骤停、释放可突然；不要所有动作都匀速或同样丝滑 |
| 弧线 Arcs | 手臂围绕关节沿弧线，头部转动与身体重心路径连贯 | 不强迫直线机构、刚性滑轨沿弧线运动 |
| 次要动作 Secondary Action | 在不改变原意的前提下，用手指、耳部或小幅姿态变化补充主动作 | 不能抢过主动作或制造新情绪；材质惯性跟随不等于独立次要表演 |
| 时间控制 Timing | 设计活停顿、突然发力、快速位移、到位制动与反应延迟；运动间距随加减速变化，形成快慢和轻重对比 | 停顿不是静帧；慢动作是展示手段，不是额外一条原则，不代替角色本身的节奏设计 |
| 夸张 Exaggeration | 加大已有动作的方向、姿势对比或情绪辨识度，选择一个重点放大 | 不默认瞪眼、大笑或全身弹跳；与原情绪和媒介的夸张幅度一致 |
| 扎实造型 Solid Drawing | 转身与遮挡后保持结构、体积、关节和透视连贯，支撑姿态可信 | 可用于二维、三维和拼贴；不把二维强改成写实三维 |
| 吸引力 Appeal | 姿势简洁可读，轮廓和节奏具有角色个性，结尾落在清楚的姿态 | 不等于统一可爱化或美化，不改变给定角色设计 |

## 常见动作的组合

### 跳跃、奔跑、碰撞

优先考虑预备、重心与接触、弧线、节奏和跟随。明确由哪里施力、何时离开支撑、如何落下、如何耗散运动。角色大幅运动时避免同时快速环绕而看不清受力。

### 手部操作

固定手、目标物和接触关系，再安排靠近、接触、受力和释放。物件运动由接触或已给定机制引起，不先于手突然位移。细微缓冲比给整个物件加弹性更适合刚体。

### 微表情与情绪变化

以指定情绪变化为边界，可让视线先落到已有目标、眉眼随后变化、嘴角最后收束。并非所有反应都适合此顺序；惊讶、压抑、困倦的起动位置和时长应不同。不按固定模板增加眨眼、流泪和呼吸。

### 环境与静物

以已有触发源、空间层次和材质作依据。已有风或水流可以使近远元素错峰响应；没有触发源的静物可保持静止，由镜头组织观看。避免把所有枝叶、衣物和粒子写成同速循环。

### 首尾帧

对比姿势、重心、位置、表情、持物和镜头方位，选必要中间姿势连接。若首帧已在半空，不倒回地面补预备；若尾帧仍在行动中，不强制静止摆拍。首尾身份或空间明显不兼容时先解决约束，不用融化变形冒充连续运动。

## 强度与材质

- 克制／写实：小幅预备、清楚受力、细微惯性，通常少用可见形变。
- 风格化动画：姿势、动作间距和节奏对比明显，柔软部位具有可读的挤压、拉伸、惯性偏移与回弹。
- 卡通喜剧：可放大轮廓与时间反差，但保持角色辨识和事件因果。

媒介或图像已有明确风格时沿用，不默认转换成“迪士尼3D”。材质写实不等于运动必须克制，用户要求强动画表演时，可以在原造型上显著放大姿势与弹性。角色有金属身体和软耳朵时分别处理，不能给全身同一种弹性。不要为了展示技术而叠加每一类细节。

## 让原则变成具体动态

对主要动作先在内部确定“意图—关键姿势—发力—惯性响应—接触或急停—回弹—下一次意图”。不强迫每个动作写全链条，但不能只给动作名称加几个形容词。

### 软组织的质量感

先有骨架和整体位移，再有软组织的延迟响应。跑步时，脚掌承重引发身体压缩，腹部稍后下沉；蹬离后骨架抬升、腹部后追，形成有因果的上下相位差。面颊、腹部与尾巴可以具有不同的延迟和恢复速度，不能完全同步摆动。

突然向右变向时，头和胸腔先指向右侧，腹部与面颊因惯性暂时偏向左侧，再向新方向追上；躯干停止后，软组织仍可越过平衡位置少许，再逐次减幅回落。前后方向需与运动相符，不能为“甩肉”随意交替方向。

保持软组织依附、关节连接和总体体积，允许轮廓发生可读变化；“保持角色一致”不能写成“身体完全不变形”。皮肉抖动是受力后的弹性响应，不是增加肥肉块、改变外貌或让身体液化。

### 活停顿与爆发

停顿用于读懂意图、蓄力或反应。例如脚掌已停，眼睛仍向目标偏移，尾尖和腹部完成余下的晃动；下一瞬后腿发力冲出。不要每个动作之间都加停顿，也不要把整段写成均匀顺滑运动。

可爱喜剧往往来自意图与身体之间的错拍：眼睛已看到新目标，身体还沿旧方向前冲；身体终于刹住，软组织还多晃一下；努力摆出威风姿势，却被最后一点回弹打断。只使用与用户情景和角色相容的表演，不另造无关事件。

### 关键姿势与动作间距

关键姿势先清楚区分蓄力、伸展、接触、反应；姿势之间的位移不等分。快速掠过的中间动作连接可读的停留姿态，让准备与爆发、紧与松形成对比。最终提示词用动作速度与位移变化表达，不依赖未经支持的帧数参数。

### 先决定看什么，再决定是否变速

慢动作应揭示正常速度下一闪而过的东西，例如腾空变向时面颊和腹部向外侧偏移、爪尖抓空、耳尖迟半拍折回。写明放慢开始和结束，期间动作继续推进，不是空中定格。保持明确的空间轨迹，不让角色在空中无支撑地改变整个重心轨迹；身体可以伸爪、扭转和调整姿态，位移仍遵循起跳产生的路径。

超级慢动作呈现的是最终播放区间，同步放慢同一时空中的蝴蝶、接触和其他可见运动，除非用户明确要选择性时间特效。恢复常速要明确；不能同一时刻既让蝴蝶常速飞远又称全场超慢。快切、慢动作与动画原则分属不同设计层面，由镜头阶段来选择，不自动出现在每项任务。

## 改写校准

不足：“小猫追着蝴蝶，身体轻微起伏，尾巴自然摆动。”

可执行：“小猫迎着镜头冲来，前爪承重时胸腹压低，后腿蹬离时身体伸展；腹部的软肉晚于躯干上下回弹。蝴蝶偏向一侧，小猫眼睛先追、头部随后扭转，腹部与面颊仍短暂滞留在转向外侧，落脚后再弹回。”

后者增加的是受力、时间差、方向与恢复过程，不是额外外貌描写。此例只用于理解写作密度，不把迎面追逐或甩肉设成所有角色和故事的默认动作。

## 把表演放回镜头检查

细节只有在“可见、可读、有时间、符合意图”时才保留。眼神微动放在远景里没有意义；衣摆大幅摆动可能遮住拿取动作；过长预备会破坏突然性。优先减掉干扰，再考虑改变允许的机位、景别或节拍。
