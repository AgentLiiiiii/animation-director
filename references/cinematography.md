# 摄影与分镜决策

从原摄影技能及其运镜、景别构图、布光知识库提炼。用于选择与修正摄影，不把参考示例的剧情、设备和排版带入用户方案。

与 [动势与镜头节奏](animation-camera-rhythm.md) 配合使用：先将表演节拍转成镜头强弱，再用本文件核对空间、手段与连续性。不要只做到技术正确却把追逐、爆发、活停顿和关怀拍成相同力度。

## 镜头为何存在

对每镜先确定：进入时观众知道什么，本镜新增什么，结束时下一镜因何发生。观察、等待与情绪停留也是有效任务，不必每镜制造反转。删去既不推进信息也不承接感受的重复覆盖。

| 需要观众看懂的事 | 候选观看方式 | 与动画表演的协同 |
|---|---|---|
| 身体如何发力、碰撞或落地 | 包含支撑点、全身和目标的全景或中全景 | 接触瞬间能看到受力，不在关键帧切走 |
| 一个细小决定或情绪变化 | 近景或特写，固定或克制推近 | 给视线、眉眼、嘴角的先后留时间；不擅自赋予新情绪 |
| 手和物件的操作关系 | 手与对象同框的局部景别 | 指尖接触、摩擦、释放和收势可辨，物件不被裁掉 |
| 某行动为何发生 | 依据已有线索建立对象关系，再展示行动 | 预备姿势指向已有目标，不让视线指向不存在的物体 |
| 结果或更大处境 | 在正确时机拉开、横移显露、转焦或切镜 | 主动作完成前不提前暴露结果，也不为揭晓虚构景物 |
| 人物互动 | 双人构图、过肩、反打或同框反应 | 角色位置、目光目标、行动轴线与动作接点一致 |

特写不是默认开场。先选信息，再选取景；不是按远景—中景—特写机械轮换。

## 运镜的起因、路径和落点

一句能执行的运动应说明：何时开始，朝哪个方向，是否跟随主体，相对距离如何变化，何时减速，最终看到什么。复杂路径可分阶段，不要同一时刻要求相反运动。

| 手段 | 准确描述 | 常见问题 |
|---|---|---|
| 固定 | 机位和朝向保持，画面内动作按原意发生 | 为证明画面“有变化”擅加人物动作 |
| 推／拉 | 镜头靠近／远离主体，机位与空间关系变化 | 与固定机位变焦混写 |
| 横移／升降 | 机位左右／上下移动，产生视差 | 只转动朝向，却要求揭示遮挡后空间 |
| 摇／俯仰 | 机位不变，朝向水平／垂直转动 | 用摇镜名称描述整机穿越空间 |
| 甩摇 | 由明确动作触发，快速转向另一个注意目标，到位制动并保留阅读瞬间 | 只写“甩镜”，没有起点、方向和落点；或借纯摇镜无故改变取景距离 |
| 跟拍 | 说明跟随对象、侧别与距离 | 同速同距跟随却无解释变成更近景别 |
| 环绕 | 绕主体移动，明确中心、方向和结束方位 | 终点已在背面却仍要求正面构图 |
| 转焦 | 从已存在的对象A转到B，机位可不动 | 把对象生成、位移或放大误写为对焦 |
| 滚转／荷兰角 | 前者绕光轴转动，后者为倾斜构图 | 混作绕主体环绕 |

固定机位变焦改变视野与主体占比，本身不改变观察位置带来的透视关系。滑动变焦需要机位移动与反向变焦协调，并有足够背景显出变化；不是先推后拉的同义词。

同一时刻有明确的注意主导，但角色与相机可以共同构成它：例如角色爆发时相机加速推近，追视转向时相机甩摇接住目标。以可读的落点、节奏和视觉层级协调，不把“大幅角色动作时相机稳定”当默认限制。切镜、相机速度、角色速度与画面变速是不同控制项，不要互相替代。

## 让镜头呈现动画的动态细节

先从已完成的表演中选最值得看的姿势、形变和反应，再选择观察方向。迎面机位可呈现冲向观众的速度与面部、胸腹惯性；侧面可呈现身体伸展、弧线和接触；略俯视可读清追逐路线。这些是可选解法，不是固定镜头顺序。

让摄影参与表演的强弱变化。可先跟随，再在伸爪或目标改变时急推到局部；也可甩摇在追逐双方之间交接注意力，再切到能读清支撑关系的中全景。各阶段写明触发、速度、景别和落点，避免只有“动感运镜”的标签。固定构图也可以与快节奏剪辑共存，在意图、发力、结果和反应处切换，用短镜推进、较长镜看清弹性或情绪。快切必须有信息差和动作衔接，不用同角度小幅变化重复展示，也不切掉碰撞的接触点或关键回弹。

局部超级慢动作需要明确最终播放区间、进入时刻、要展示的部位及形变方向、退出时刻。它放慢的是场内动作，不只是相机移动；同一时空的角色与物件采用一致动作时间，区间结束恢复常速。虚拟相机可另行设计为在播放时间内快速推进，再稳定阅读局部，不默认跟着角色等比例放慢。变速后的时长计入完整单元，以可见结果描述，无需虚构帧率或平台参数。

运动机位、剪辑速度与画面变速协同，可以在重音处集中加强，再主动收束；不能持续全强或全弱。让强动态与短暂活停顿形成对比，快动作里留下能看清角色意图的姿势。对强动势任务，整段匀速同距跟随或同景别覆盖且没有具体理由时，返回重设镜头节拍。

## 景别、构图与焦点

- 关键姿势先看轮廓能否读懂：手与躯干、头与道具不要叠成一团。默认可通过机位和取景改善；锁定的站位不能为构图偷偷移动。
- 主动作需要身体与目标同时可辨。先呈现接触关系，再用近景读反应；不要让表情特写吞掉必须展示的行动。
- 浅景深只用于引导注意；动作对象和后续必要信息不能全被虚化。转焦对象需原本存在于空间中。
- 用已有空间的前中后层次与留白，不为过肩镜头添人，不为前景遮挡添树枝。相机路径不穿过未说明可穿越的实体。
- 切换时核对空间轴线、屏幕方向、视线目标、左右手与动作进度。越轴可以有意使用，但用可见运动或建立空间的镜头让观众读懂。
- 镜头角度、景别和情绪之间是情境关系，不是确定公式；俯拍可温柔，仰拍也可滑稽。

## 光影与动画材质

保留给定时段、天气、场景光源与配色。未说明光源时可以写“柔光从角色侧上方照来”，不擅自写成“夕阳穿过百叶窗”。

分别控制方向、阴影边缘软硬、明暗分布和画面冷暖，不混为一个“电影光”标签：

- 软硬描述阴影过渡，不等于反差高低；柔光也可以有深暗部。
- 低调保留足够暗区，但关键表情和动作仍可读；不等于整体欠曝。
- 通过主体与背景的局部明度或色彩差异增强轮廓，不默认加橙青、轮廓光或雾中光束。
- 硬质、柔软、透明材质保持各自特征；主体转动时高光和阴影随空间关系变化，不像贴图贴在屏幕上。
- 光源色温、白平衡和最终画面色调分别考虑；不同光源可按意图混合，不强制统一色温。
- 同场光源位置稳定。反打改变画面内光向关系，不自动移动光源；没有事件依据时不让灯光追着情绪变色。
- 将“负填充”表达为背光侧更暗但仍可辨认，不把灯架、旗板或柔光箱生成为场内道具。

## 多场景与参考素材

按地点、时间和事件连续性划分场景。每场独立确定叙事重点和照明依据，跨场不强制复用同一灯位；人物状态、持物、情绪方向与事件顺序继续衔接。

参考视频和失败结果中，区分实际观察与推测。截图不能证明速度，单张图不能证明动作顺序或实际焦距。若只能抽帧，用带时间位置的连续采样检查目标区间；证据不足时只描述用户反馈和可见问题，不声称诊断了所有运动。
