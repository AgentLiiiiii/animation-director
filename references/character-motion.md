# 角色动势分级与逐动作约束

这是本技能为表演设计建立的工作分级，不是迪士尼官方角色分类。十二原则适用于所有等级；等级改变幅度、节奏、作用部位及表达方式，不改变需要考虑的原则数量。

## 表演前建立内部角色设定

对每个实际参与情节的角色，包括人、动物和其他行动主体，结合参考图与本段情景判断：

`角色 → 情景目标与性格表达 → 体型／质量分布／可动结构 → 主动动势 → 弹性响应 → 表情强度及部位 → 本段强弱变化 → 必须呈现的动态特征`

用户已指定的分级优先；资料足够时自主判断，不增加问卷。不能仅凭年龄、胖瘦或物种决定全部等级：体型主要帮助判断质量与软组织响应，情景行动、情绪与用户风格要求决定如何表演。大体型可以沉稳，年长角色也可能有爆发动作，不将单个案例变成刻板模板。

### 主动动势

| 等级 | 主要动作要求 | 动静与节奏 |
|---|---|---|
| 强 | 姿势轮廓和行动方向鲜明；大动作有充分蓄力、突然释放、明显到位或制动；激烈动作之间的快慢差清楚 | 高能动作与活停顿交替，不全程平均快或全程抖动；意图可先走，身体后追 |
| 中强 | 明确预备、动作弧线、重心和有表现力的姿势；关键时刻放大，其余动作适度收束 | 节奏有起伏和选择性强调，不每一步都推到极限 |
| 弱 | 肢体幅度小而清楚，重心转移稳，启动与停止柔和；表演可以主要落在眼神、头部或手部 | 允许长些的观察和停留；微小先后、停顿与收势仍有设计，不能写成无生命的静止 |

### 弹性响应：与主动动势分开决定

| 等级 | 可见响应 | 适用判断 |
|---|---|---|
| 强 | 明显压缩与伸展、横向拉扯、软组织与骨架错相、越过终点后减幅回弹；正常播放也应能读到主要变化 | 软组织丰富且本段要求强风格化弹性；按局部质量分布设计，不平均给全身相同振幅 |
| 中 | 接触、转向和急停等节点有清楚形变或附件跟随，其余过程适度收束 | 保持结构，以关键姿势和局部响应强调动作 |
| 弱 | 以关节、姿态和重心变化为主；形变细微或只出现在允许的柔性部位 | 刚性结构、克制表演或用户指定的弱弹性角色；仍需重量和缓冲 |

速度快不等于软组织强弹性。蝴蝶可有灵活快速的路径和翅膀节奏，但不用胖猫式腹部甩动。刚体角色可强动势、弱本体形变，通过关节、分段错拍或柔性附件表达夸张。

### 表情与次要表演

分别指定眼神、眼睑、口部、头部、手指、耳尾等可用部位的强度和主次。弱身体动势可以配灵动的眼神；强身体动作也可以配执拗、克制的脸。不要让所有部位同时达到最大幅度。

## 从角色设定落实到每个动作

在内部逐动作记录：

`动作与目标 → 活停顿／预备姿势 → 发力与速度变化 → 受力形变部位及方向 → 滞后部位 → 接触或制动 → 越过终点与恢复 → 接续动作`

对强动势、强弹性的软角色，下列适用动作都必须有对应设计，不只挑一个亮点：

| 动作 | 应能读到的强弹性过程 |
|---|---|
| 起跑与奔跑 | 蓄力压缩与蹬离伸展形成轮廓对比；脚掌承重引发胸腹下压，腹部和面颊随后回弹，不同步成一团 |
| 变向与绕圈 | 目光和前躯先指向新目标，后躯慢半拍；软肉向转弯外侧偏移，再追上骨架，内外侧受力不同 |
| 急停 | 支撑先制动，软组织仍沿原方向前冲，超过平衡位置后拉回、减幅；在余动结束与下次发力间形成可读停顿 |
| 起跳与抓扑 | 预备压缩明显，发力时沿动作线伸展；四肢、躯干和软组织有先后，抓空后不能无原因重置身体形状 |
| 落地与碰撞 | 接触点先受力，四肢缓冲、身体压低或横向展开，软组织继续下沉后回弹，能量逐步消散 |
| 被抱起、支撑或摸头 | 由外力决定压缩与延迟：承托先建立，身体随后上升，软组织稍晚收拢或下垂；抚摸可引发局部压缩和恢复，不让全身无源抖动 |

明确强度，不把所有句子都弱化成“轻微、少许、自然”。强弹性可以写“明显压扁后弹开、腹部大幅向外侧拖曳后追上、两颊先冲过停止位置再回弹”；同时保留总体体积、组织依附、关节和接触因果，不形成身体融化或漂移。

每段不必把表格所有词写全，但选定的效果必须进入最终时间线。若角色强度在中段降低，必须有可理解的原因，例如进入观察、被承托或行动目标改变，而不是遗漏了动态描写。

## 一动一静不是不停弹跳

动静反差有三个可独立安排的层次：整个身体快动与停住；骨架已停、软组织仍动；身体静、目光或尾尖先动。三者服务情绪和注意力，不循环重复相同停顿。

强角色进入静段时先让惯性结清，再保留少量有意图的动作。弱角色也能在必要节点短暂加强，但不能因为与强角色同框就继承对方的弹性。镜头节奏依各角色的注意重点安排，不把全场一律处理为快切或慢动作。

## 当前追蝶情景的校准例

| 角色 | 本段设定 | 跨动作的统一要求 |
|---|---|---|
| 小猫 | 追逐时强主动动势、强软组织弹性；目标锁定与恼怒表情清楚 | 跑、转、停、跳、落均有明显拉扯和回弹，强弱节拍连续；被抱起后整体位移由奶奶控制，仍保留承托处压缩、抬头后的面颊余动等局部弹性 |
| 奶奶 | 弱主动动势、弱整体弹性；眼神和手部温柔而有先后 | 走近、俯身、承托、摸头重心清楚，眼睛先关切、动作随后响应；不增加大幅压缩伸展或全身甩动 |
| 蝴蝶 | 中强路径变化与轻快节奏，弱躯干形变 | 翅膀与飞行弧线轻巧，落下有短暂静段，重新起飞有清楚释放；与小猫的沉重弹性形成对比 |

此例采用本次用户要求，不据此把所有猫、老人或蝴蝶固定为相同等级。用户提供影视人物作参照时，将其作为所需表现强度的参考，不能把示例说成官方分级或照搬其造型。

## 交付前逐动作核对

1. 每个行动角色都有基准动势、弹性、表情及段落变化判断。
2. 强软角色所有适用的大动作均有可见形变、错峰响应与恢复，不是只在一个慢镜头中强弹性。
3. 各动作受力方向和回弹方式不同，主体停后有衰减，不复制同一全身抖动。
4. 弱角色保持克制，但眼神、手势和重心不呆板；强角色的风格没有传染给同框角色。
5. 每个选定效果在相应机位、景别与播放时长中能读到，不能只存在于内部分析。

未达到设定强度且无剧情或锁定约束依据的动作，应返回重写。最终输出仍只有画面内容、时间线、全局约束，不追加动势表；仅在用户要求检查设计方法时展示分析。
